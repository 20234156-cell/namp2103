# Project_study - Bài tập Lập trình Java

Các bài tập Java cơ bản, mỗi bài là một file độc lập có thể biên dịch và chạy riêng.

## Danh sách bài

| Tên bài | File | Yêu cầu |
|---------|------|---------|
| Tính tổng số chẵn | `TinhTongSoChan.java` | Nhập n nguyên dương. Tính s = 2 + 4 + ... + n. Nếu n lẻ, tính đến số chẵn lớn nhất nhỏ hơn n. |
| Tính tổng nghịch đảo | `TinhTongNghichDao.java` | Nhập n nguyên dương. Tính s = 1 + 1/2 + ... + 1/n. |
| Kiểm tra số nguyên tố | `KiemTraSoNguyenTo.java` | Nhập số nguyên n. Kiểm tra n có phải số nguyên tố hay không. |
| Kiểm tra và phân loại tam giác | `KiemTraTamGiac.java` | Nhập 3 số a, b, c. Kiểm tra có phải 3 cạnh tam giác không. Nếu có, xác định loại tam giác. |
| Hiển thị dãy Fibonacci | `DayFibonacci.java` | Nhập n nguyên dương. Hiển thị n số Fibonacci đầu tiên dạng 0 1 1 2 3 5 8 ... |

## Cách biên dịch và chạy

Yêu cầu đã cài JDK (Java Development Kit).

```bash
# Biên dịch một bài
javac TinhTongSoChan.java

# Chạy
java TinhTongSoChan
```

Ví dụ chạy bài Fibonacci:

```bash
javac DayFibonacci.java
java DayFibonacci
```
